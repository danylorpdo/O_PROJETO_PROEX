# Dashboard PRF Paraná

Abra o dashboard a partir do projeto completo. A interface lê a base consolidada, os gráficos da Etapa 02 e os resultados da Etapa 03. Os modelos são avaliados antecipadamente, de acordo com os comandos do [README do projeto](../../README.md#instalação-dashboard-e-testes).

Execute `bash outputs/dashboard_prf/iniciar.sh` na raiz, ou abra `iniciar.bat` no Windows, e acesse [localhost:8501](http://localhost:8501).
